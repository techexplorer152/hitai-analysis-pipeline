# HITAI Combat Video Analysis Pipeline


A full-stack real-time tracking application that simulates processing boxing and combat sports video footage

## 💻 How to Set  Up & Run

### 1. Start the Backend Server (Terminal A)

Then run:

pip install fastapi uvicorn pydantic sse-starlette

uvicorn main:app --reload

### 2. Start the Frontend Page (Terminal B)
Open a new terminal window, navigate to the frontend directory, and start the dashboard:



npm install

npm run dev
